# Site acadêmico de Lourival Rodrigues de Lima

Projeto Quarto completo, em inglês e espanhol, preparado para GitHub Pages.
Leia primeiro **COMECE-AQUI.md**. Não é necessário usar o terminal para publicar.

## Conteúdo
- `index.qmd`: página inicial em inglês.
- `research.qmd`: interesses e projetos.
- `publications.qmd`: seleção inicial de publicações.
- `teaching.qmd`: atividade docente.
- `cv.qmd`: currículo resumido.
- `notes.qmd` e `notes/`: notas matemáticas.
- `es/`: versões em espanhol; traduções são editadas separadamente.
- `assets/`: design e navegação bilíngue.
- `files/`: documentos públicos para download.
- `.github/workflows/publish.yml`: compilação e publicação automática.

## Prévia local opcional
Instale Quarto: https://quarto.org/docs/get-started/
Na pasta do projeto, execute `quarto preview`. Para compilar: `quarto render`.
A versão usada na automação é 1.8.27. R, Python e LaTeX não são necessários para este site.

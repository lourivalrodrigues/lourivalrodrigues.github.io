# Design e fontes

## Direção visual
Fundo branco quente (#faf9f5), texto azul escuro (#182a37) e detalhes verde petróleo (#166b70). Nome em tipografia serifada; texto e navegação em fontes do sistema. Layout sem fotografia, com margens amplas e duas colunas que se tornam uma no celular. Acessibilidade: foco visível, links sublinhados no texto, navegação por teclado e hierarquia de títulos.

## Arquitetura
Um projeto Quarto renderiza 14 páginas. Inglês na raiz; espanhol em es/. A troca de idioma preserva a página correspondente. As traduções são independentes; JavaScript ajusta os rótulos e destinos do menu para cada idioma. Cada página também possui um link explícito para a tradução. A pesquisa interna é fornecida pelo Quarto. O CV tem estilos próprios para impressão.

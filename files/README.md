Esta pasta receberá PDFs públicos de aulas, artigos e currículo.
Para adicionar um documento, copie o PDF aqui e crie um link no arquivo .qmd correspondente.
Exemplo em uma página na raiz: [Baixar PDF](files/nome-do-arquivo.pdf).
Exemplo em uma página dentro de es/: [Descargar PDF](../files/nome-do-arquivo.pdf).
Use nomes sem espaços e publique apenas versões cuja divulgação você autorizou.
